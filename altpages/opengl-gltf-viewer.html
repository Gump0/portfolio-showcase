opengl-gltf-viewer is a lightweight gltf model viewer built solely with C++17, OpenGL, glfw and ImGUI. With the purpose of learning the basics of 3D graphics, shader scripting and how games load, render and texture 3D models under the hood.


The viewer supports the following:


  • Load and render .gltf models
  • Point-light and ambient lighting simulation done with GLSL shader scripting
  • Support for specular maps
  • ImGui-powered UI panel for scene manipulation
  • Supports loading textures and meshes (uv's, normals, vertices)
  • First-person camera controls (orbit, pan)
